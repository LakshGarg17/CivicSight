# Week 10 — Frontend Testing and Bug Fixes

## Work Done This Week
This week, I focused on testing the CivicSight frontend, fixing interface issues, and checking how the application behaves under different conditions.

### Frontend
- Tested the citizen reporting page, municipal dashboard, and maintenance interface.
- Tested invalid form inputs and image upload failures.
- Checked the fallback behavior when browser location permission was denied.
- Fixed UI issues and checked the layout on different screen sizes.

### Backend
- Tested frontend integration with report submission, verification, and repair-update APIs.
- Checked how the interface handled failed requests and unexpected responses.
- Verified that report statuses were displayed correctly after updates.

### ML
- Tested the display of detection results for different road images.
- Checked how the interface behaved when detection results were missing or inference failed.
- Verified that the ML assessment remained separate from municipal verification.

## Result
The frontend was tested across the main CivicSight workflows, and interface issues and error-handling problems were identified and addressed.
