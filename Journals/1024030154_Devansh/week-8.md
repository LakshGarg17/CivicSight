# Week 8 — Priority Display and Related Reports

## Work Done This Week
This week, I worked on improving the municipal dashboard to help officers understand report priority and identify potentially related complaints.

### Frontend
- Added priority and severity information to the report details page.
- Displayed the reason behind a report's priority, such as damage severity or repeated reports.
- Added filters to help officers find high-priority reports.
- Worked on showing nearby or potentially related reports where appropriate.

### Backend
- Tested the dashboard against reports containing priority, severity, and repeated-report information.
- Helped verify that priority reasons and related-report details were returned correctly by the backend.
- Checked that the frontend handled reports with missing or unavailable assessment information.

### ML
- Tested how different detected damage classes appeared in the report assessment.
- Checked whether confidence values were displayed and interpreted consistently.
- Reviewed sample detections to identify any obvious issues affecting severity assessment.

## Result
The municipal dashboard provides a clearer view of report priority and helps officers identify high-priority and potentially related complaints.
