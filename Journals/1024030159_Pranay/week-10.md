# Week 10 — Backend Testing and Workflow Validation

This week, I focused on testing the backend APIs, database consistency, authentication, and report lifecycle.

### Frontend
- Tested report submission and status updates through the application interface.
- Checked that error messages appeared for failed requests.
- Verified that the dashboard reflected backend status changes correctly.

### Backend
- Tested report, authentication, and maintenance APIs.
- Checked authentication and role-based authorization for citizens, municipal officers, and maintenance staff.

- Fixed backend issues identified during testing.

### ML
- Tested the backend's handling of successful and failed inference requests.
- Checked that detection results were associated with the correct reports.

The backend workflows were tested for correctness, access control, and error handling. Issues discovered during testing were addressed to improve system reliability.
