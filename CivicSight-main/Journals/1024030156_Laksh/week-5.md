# Week 5 — Report APIs and Municipal Access

## Work Done This Week

This week, I focused mainly on the backend support required for the municipal dashboard while also working with the frontend and ML workflow.

### Frontend
- Tested the municipal reports table with real data returned from the backend.
- Worked on displaying report status and priority clearly.
- Tested report details and filtering from the dashboard.

### Backend
- Implemented the report listing API for municipal users.
- Added a report-detail API to retrieve individual report information.
- Added filtering by status and priority.
- Added officer-only access for municipal report management.
- Implemented and tested the report verification endpoint.

### ML
- Reviewed the results from the first YOLO training experiments.
- Compared detection results and checked precision, recall, and mAP values.
- Helped identify a reasonable baseline model for further testing.

## Result
The backend can provide filtered reports to authorized municipal users and supports viewing and verifying individual reports.
