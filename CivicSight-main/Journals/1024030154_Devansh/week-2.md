# Week 2 — Frontend Development

## Work Done This Week
This week, I worked on building the basic frontend structure for CivicSight. The main focus was to move beyond the initial landing page and start creating the actual road damage reporting interface.

I improved the landing page and added a simple navigation structure so that the user can easily understand what CivicSight does and where to go to report a road problem.

I also created the basic **Report Road Damage** page. The page currently contains an image upload section where a citizen can select a photograph of the damaged road. A description field was also added so that the user can provide additional information about the problem.

A location section has been added as a placeholder. At this stage, it is not connected to the backend or map services yet. The idea is to later allow the application to obtain the user's current location or allow the user to select a location manually.

For now, the interface has intentionally been kept simple because the backend integration and final data flow have not been implemented yet.

## What I Learned
I got a better understanding of how the different frontend components will eventually communicate with the backend. I also worked on structuring the reporting page in a way that can later accept data from APIs without requiring major changes to the interface.

## Challenges
One of the main challenges was deciding what information should actually be collected from a citizen. We wanted the reporting process to remain simple while still collecting enough information for the municipal side of the system.

Another consideration was keeping the interface flexible because the exact location and report submission workflow will be finalized when backend integration begins.

## Current Status
The basic frontend reporting interface is now in place. Image upload, description input and the initial location section are ready for further integration.
