# Week 1 : Project Setup and Understanding

## Objective

The objective of Week 1 was to understand the overall CivicSight project and prepare the frontend development environment without starting major feature implementation.

## Work Completed

### 1. Understood the CivicSight Project

Studied the overall purpose and workflow of CivicSight — a Smart Road Damage Detection and Municipal Repair Management System.

The main workflow identified was:

**Report → Detect → Prioritize → Verify → Assign → Repair → Close**

I also understood the role of the frontend in connecting citizens with the CivicSight backend and presenting information to municipal personnel.

### 2. Created the Frontend Structure

Created the initial frontend folder structure for the project.

The structure provides separate areas for:

- HTML pages
- CSS styling
- JavaScript functionality
- Static assets

This gives the frontend a clean foundation for future development.

### 3. Created the Initial Landing Page

Created the initial CivicSight landing page with basic project information and navigation.

The page introduces the purpose of CivicSight and provides the starting point for future citizen and municipal workflows.

### 4. Set Up HTML, CSS and JavaScript

Created the initial HTML, CSS and JavaScript files.

At this stage, the focus was on establishing the frontend foundation rather than implementing complete functionality.

### 5. Added CivicSight Branding

Added the CivicSight branding and initial visual identity to the frontend.

The design direction was kept professional and suitable for a civic technology platform.

### 6. Created Basic Navigation

Added a simple navigation structure that can later be extended to include features such as:

- Report Road Damage
- Track Reports
- Municipal Dashboard
- About CivicSight

## Challenges / Observations

The main challenge during this week was deciding how to structure the frontend so that it can later communicate cleanly with the backend.

Since the reporting interface will eventually require image upload, location capture and API communication, the initial structure was kept modular rather than building everything into a single page.

## Learning

This week helped me understand the overall system requirements and the importance of establishing a clean frontend structure before implementing major features.

I also became familiar with how the frontend will eventually interact with the backend through APIs.

## Week 1 Outcome

The frontend now has a basic working structure, landing page, CivicSight branding and navigation foundation. It is ready for development of the citizen reporting interface in the next phase.
